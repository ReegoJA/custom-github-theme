# Contributing

Keep the component buildless and dependency-free unless a clear need justifies a change. Use two spaces, single-quoted JavaScript strings, semicolons, descriptive names, and concise exported-function documentation. Reference styles are linked in the README.

Edit the component in `src/`. Keep all queries scoped to its ShadowRoot, insert remote text with `textContent`, and never add frontend credentials. Keep profile data and example fixtures distinguishable. Do not fabricate contribution counts or repository activity.

Run `npm test` and preview with `npm start`. Check profile changes, two instances on one page, back navigation, keyboard controls, file previews, loading/errors, and narrow containers when relevant. Preserve focus visibility and readable contrast.

Update README, CHANGELOG, credits, and file explanations when behavior or dependencies change. Credit actual maintainers and contributors, reference authors are not code contributors by implication. Keep the MIT notice with redistributed code.


Do not commit credentials, local configuration, unrelated personal documents, or invented metrics. Submit a focused pull request with the behavior change and relevant verification.
